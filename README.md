# Lavacar

Experiência web estática inspirada em dashboard premium para gestão de lavação com dois acessos dedicados.

- **Portal do cliente (`index.html`)**: destaque comercial, consulta de horários, planos recorrentes, formulário completo de agendamento, lista de pagamentos e painel de dicas.
- **Painel da equipe (`equipe.html`)**: visão operacional diária com métricas, tarefas em tempo real, confirmações de pagamento, estoque e comunicados internos.

## Como visualizar

Abra os arquivos `index.html` ou `equipe.html` diretamente em qualquer navegador moderno. Não há dependências externas além do CSS/JS incluídos, portanto nenhum processo de build é necessário.
